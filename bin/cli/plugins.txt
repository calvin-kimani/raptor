# Raptor Plugin Registry
# Format: plugin_name:git_url:branch:path/to/install.py
#
# Each plugin is fetched from a remote git repository and must have an install.py that defines:
# - TOOL_INFO: dict with name, description, version, commands
# - DEPENDENCIES: dict of required packages
# - install(): function to install dependencies
# - register_commands(subparsers): function to register CLI commands
#
# Example:
# agents:https://github.com/user/raptor.git:feature/agents:cli/plugins/agents/install.py
